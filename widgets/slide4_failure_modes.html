Slide 4 · Failure Modes: What You Observe

Six generic failure modes in three families, coloured like slide 3.

Thinking failures
Goal drift
See: wanders off the original ask
Cause: long, crowded context
Example: asked to summarise a report, starts rewriting it
Wrong tool
See: right intent, wrong action
Cause: too many similar tools
Example: sends the email instead of drafting it
Acting failures
Infinite loop
See: same step again and again
Cause: no step limit, no memory of failures
Example: keeps re-searching the same flight
Error cascade
See: one bad step spoils the rest
Cause: no isolation or checkpoints
Example: wrong customer ID used in every later step
Checking failures
False success
See: says "done" when it isn't
Cause: grades its own work
Example: "report sent" but the attachment is empty
Premature stop
See: quits halfway, sounds confident
Cause: "stopped talking" read as "finished"
Example: answers 2 of 5 questions

Every failure is one of three jobs going wrong, and every cause is a design choice.
